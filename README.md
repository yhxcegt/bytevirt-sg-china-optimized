3. **首次登录**：用 SSH 客户端（Termius、PuTTY、iTerm 都行）连 IPv4 地址，root 账号 + 邮件里的初始密码。
4. **基础加固**：改 SSH 端口、禁用 root 密码登录、开密钥登录、装 fail2ban，这几步别省。
5. **网络优化**：装 BBR + FQ 拥塞控制算法，对这种带宽型 VPS 提升明显。一行命令：
   bash
   echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
   echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
   sysctl -p
   
6. **跑分验证**：用 `bench.sh` 或 `lemonbench` 跑一遍，对比官方宣传的 EPYC 7D12 性能是否对得上。
7. **流媒体验证**：用 `RegionRestrictionCheck` 脚本测一遍解锁情况，确认区域识别为 SG。
